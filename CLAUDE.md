## Git workflow

Do new work on a feature branch — create one before starting if not already on one. Push it to `origin` when finished; don't commit directly to `main`.

## Agent skills

### Issue tracker

Issues live in GitHub Issues for `jstromwick/assistant-coach`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
